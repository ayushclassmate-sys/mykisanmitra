# Kisan Mitra & Environmental Monitoring System

## About the Project
Kisan Mitra is an AI-powered agricultural support platform designed to help farmers make informed decisions. The Environmental Monitoring System monitors temperature and humidity using sensors.

## Key Features
- Crop selection and cultivation guidance
- Market prices and Minimum Support Price (MSP) information
- Government schemes and agricultural resources
- Agri Bazaar and ODOP Shop
- Environmental monitoring using temperature and humidity sensors

## Technology
AI, web technologies, microcontrollers, and environmental sensors.
